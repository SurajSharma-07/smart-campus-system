# Presentation / Demo Checklist

1. Start MySQL.
2. Run `database/database.sql` in MySQL Workbench.
3. Start backend on port 5000.
4. Start frontend on port 5173.
5. Login as student and create a complaint.
6. Show automatic department routing and ticket generation.
7. Open My Complaints and show filters + status badges.
8. Open a complaint and demonstrate the activity timeline.
9. Sign out and login as admin.
10. Show dashboard KPIs, pipeline chart, and department workload.
11. Open All Complaints and update a complaint status/priority/department.
12. Return to student and show the generated notification.

Suggested presentation talking points are intentionally not included; build the 15–20 slide presentation from the actual application flow and database design.
